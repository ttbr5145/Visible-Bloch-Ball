# 单量子比特 Bloch 球可视化

交互式可视化工具，通过几何方式展示单量子比特的量子态及其在 Bloch 球上的表示。

## 功能特性

- **3D Bloch 球**：可拖拽旋转、缩放的交互式球体模型
- **角度控制**：通过滑杆调节极角 θ 和方位角 φ
- **量子门算子**：支持 X、Y、Z、√X、√Y、S、T、Hadamard 门
- **五种量子态表示**：同时展示标准形式、极坐标形式、对称形式等五种等价表达式
- **实时数据**：显示概率幅、Bloch 矢量坐标、相干性等物理量
- **动画演示**：量子门作用以平滑动画呈现

## 技术栈

- Three.js 0.160.0（3D 渲染）
- 原生 JavaScript（ES Module）
- 单 HTML 文件，无构建依赖

## 使用方法

直接在浏览器中打开 `index.html` 即可运行。

## 量子态表示

任意单量子比特态可表示为：

```
|ψ⟩ = α|0⟩ + β|1⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩
```

其中 θ 和 φ 对应 Bloch 球上的极角和方位角。
